# Advanced Password Strength Checker

## Overview
This project is an advanced password strength checker built using Python and Tkinter.

## Features
- Password strength analysis
- Password generator
- Common password detection
- Regex validation
- GUI application

## Technologies Used
- Python
- Tkinter
- zxcvbn
- Regex

## Installation

```bash
pip install zxcvbn
python password_checker.py
```

## Learning Outcomes
- Secure password practices
- GUI development
- Python programming
- Cybersecurity fundamentals
